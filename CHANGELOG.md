# Changelog

## 1.0.0 — 2026-07-30

Initial public release.

- Very opinionated, domain-first Swift Testing workflow for TDD/BDD
  (`when..._then...` naming, `makeSUT`, deterministic doubles)
- Nine reference guides: foundations, core rules, async & errors, test doubles,
  structure & quality, parameterized tests, traits & known issues, common
  mistakes, and Swift 6.1/6.2+ features
- Installable via the skills CLI, Claude Code plugin marketplace, Cursor, pi,
  or manual symlink
